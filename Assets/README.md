# App icon

`AppIcon.png` is the source artwork for the application's macOS icon. `build.sh` generates the standard icon sizes and packages them into `AppIcon.icns` in the app bundle.

Created with the built-in image generation tool using this prompt:

> Use case: logo-brand. Asset type: final macOS application icon for a tiny utility named Screen Toggle that turns the built-in display off and on. Create one beautiful abstract icon, not a presentation or mockup. A single bold sculptural geometric mark: two offset rounded rectangular planes, one illuminated and one falling into shadow, suggesting a transition between light and darkness. Minimal, precise, striking silhouette, subtle depth and soft luminous material, restrained sophisticated contrast, instantly legible at small sizes. Center it on a rounded-square macOS icon tile with consistent generous internal margins. Straight-on orthographic view, no perspective tilt of the whole tile. The tile occupies about 88 percent of the square canvas and has smooth continuous rounded corners. Outside the tile is genuinely transparent alpha, no checkerboard. 1024 by 1024 square. No text, letters, numbers, power-button symbols, laptop illustrations, screen diagrams, extra objects, border frame, watermarks, or surrounding scene. Deliver only the finished single icon.
